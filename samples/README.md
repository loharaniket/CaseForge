# ThreatTrace AI — Sample Test Datasets

This directory is designated for sample `.eml` and forensic email test artifacts.

## Safety & Quarantine Rules
1. **Never commit live malicious payloads**: Sample emails containing active exploits, macro malware, or zero-day scripts must be defanged or safely anonymized.
2. **Untrusted Input**: All files loaded from this directory during development and automated testing must be processed with strict validation.
